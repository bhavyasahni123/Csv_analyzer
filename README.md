# Datara

### Explore your data. Discover insights.

Datara is a desktop application for analyzing tabular data, exploring datasets, and generating interactive visualizations and reports — all through a clean, dark-themed interface.

## Features

- **Data Exploration** — Load and preview CSV, TSV, and TXT files.
- **Data Analysis** — Explore datasets using built-in analysis features.
- **Interactive Visualizations** — Generate charts powered by Plotly.
- **HTML Reports** — Generate reports for reviewing and sharing insights.
- **Desktop Experience** — A standalone Windows application built with Python and PyQt6.

## Installation

### Windows

1. Download the latest **Datara Setup** `.exe` from the [Releases](https://github.com/bhavyasahni123/Csv_analyzer/releases) page.
2. Run the downloaded installer.
3. Follow the installation instructions.
4. Launch **Datara** from the Start Menu or desktop shortcut.

That's it — no Python installation or manual dependency setup required.
